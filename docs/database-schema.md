# Database Schema

The working schema is implemented in `database/schema.sql`.

SQLite is the current technical baseline, subject to final confirmation with the assigned Database Team for collaboration evidence.

## Required Tables

- `locations`
- `roads`
- `restaurants`
- `customers`
- `riders`
- `orders`
- `algorithm_runs`
- `audit_events`

The schema supports the brief's required entities while adapting them to the food delivery domain.
