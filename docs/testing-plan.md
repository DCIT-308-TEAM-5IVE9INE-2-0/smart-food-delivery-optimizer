# Testing Plan

The project requires at least 40 tests across data structures and algorithms.

## Test Categories

- Normal cases.
- Boundary cases.
- Invalid-input cases.
- Empty structure cases.
- Single-element cases.
- Duplicate-key cases.
- Queue full and empty cases.
- Hash collision cases.
- Disconnected graph cases.
- Unreachable route cases.
- Binary search on unsorted input as an invalid precondition example.

## Required Trace Tables

- Binary search.
- Insertion sort.
- Merge sort or quicksort.
- Dijkstra.
- Kruskal or Prim.
- Dynamic programming.
