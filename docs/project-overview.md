# Project Overview

Official title: SMART FOOD DELIVERY

Repository name: `smart-food-delivery-optimizer`

SMART FOOD DELIVERY is a Ghana-localized food delivery and rider dispatch optimizer for the University of Ghana DCIT 204/308 Joint Data Structures and Algorithms Semester Project.

The system represents a local service operating around the University of Ghana, Legon, East Legon, Madina, Haatso, Adenta and nearby communities. It stores operational data in SQLite, loads records into custom-built data structures, applies algorithms to solve delivery operations problems, and records evidence for correctness and performance analysis.

## Core Purpose

The system should help answer questions such as:

- Which food order should be handled next?
- Which rider should be assigned to an order?
- What is the shortest route between two locations?
- Which locations are reachable from a dispatch point?
- Which orders should be selected under time, capacity or budget constraints?
- How do different data structures and algorithms perform as input grows?

## Final Technical Baseline
