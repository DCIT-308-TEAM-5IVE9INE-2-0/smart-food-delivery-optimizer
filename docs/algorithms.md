## Food Delivery Mapping

- Linear search: search unsorted records.
- Binary search: search sorted records.
- Sorting: order records by time, urgency, distance or deadline.
- BFS: find reachable nearby locations.
- DFS: traverse the delivery network.
- Dijkstra: find shortest delivery routes.
- Prim and Kruskal: generate minimum connection networks.
- Greedy: assign nearest available rider.
- Dynamic programming: select orders under time, budget or capacity limits.
- Brute force: compare all assignments for small input sizes.
