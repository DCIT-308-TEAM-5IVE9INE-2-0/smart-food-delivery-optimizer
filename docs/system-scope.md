# System Scope

## In Scope

- Store and manage locations, roads, restaurants, customers, riders, orders, algorithm runs and audit events.
- Load database records into custom data structures.
- Process normal orders using FIFO queues.
- Process urgent or delayed orders using priority queues and heaps.
- Rotate available riders using a circular queue.
- Search records using linear and binary search.
- Sort orders using selection sort, insertion sort, merge sort and quicksort.
- Represent the road network using adjacency lists and adjacency matrices.
- Run BFS, DFS, Dijkstra, Prim and Kruskal.
- Demonstrate greedy rider assignment and a greedy counterexample.
- Demonstrate dynamic-programming order selection.
- Record algorithm experiment results for CSV export and graphing.
- Provide tests, traces, proof sketches and screenshots for the final report.

## Out of Scope

- Production mobile app or web app.
- Real online ordering.
- Real customer personal data.
- Payment processing.
- Live traffic API integration.
- Enterprise-level dispatch optimization.
